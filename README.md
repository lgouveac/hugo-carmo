# Hugo Carmo — Portfólio

Site de portfólio e venda de obras do artista visual **Hugo Carmo**.

Página única (`index.html`) com:
- **Hero** com galeria animada
- **Comprar obras** — prints e quadros com moldura
- **Fotografias** — galeria com 34 fotografias (Brasil e exterior)
- **Na sua parede** — sugestões de montagem das obras emolduradas
- **Exposições** e contato via WhatsApp

## Stack
HTML estático + [Tailwind CSS](https://tailwindcss.com) (CDN), [GSAP](https://gsap.com) e [Lucide](https://lucide.dev). Sem build.

## Rodar localmente
```bash
python3 -m http.server 8000
# abra http://localhost:8000
```

As imagens da galeria ficam em `images/`.
